
# Music Data Explorer

## About the Project
Music Data Explorer is a beginner-friendly data analysis project built with Python and pandas. It uses a sample music dataset to explore song artists, release years, and stream counts.

## Tools Used
- Python
- Pandas
- CSV

## Dataset
The dataset contains sample information about six songs, including the song title, artist, stream count in millions, and release year.

**Note:** The stream counts are sample figures for learning and are not verified real-world streaming totals.

## Analysis
This project currently answers two questions:
1. Which song has the highest stream count in the dataset?
2. What is the average stream count across all songs?

## How to Run
1. Install Python.
2. Install pandas using `python -m pip install pandas`.
3. Download `main.py` and `songs.csv` into the same folder.
4. Run `python main.py` in the terminal.
